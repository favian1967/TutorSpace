# Техническое задание

## Десктопное приложение «TutorSpace» — недельное расписание заданий для преподавателя и ученика

### 1. Цель

Перенести существующий веб-сервис TutorSpace (Django + React, репозиторий
`github.com/favian1967/teacher_system`) в самостоятельное десктопное приложение для Windows,
которое запускается из Visual Studio без веб-сервера, фронтенда и Docker.

### 2. Технологии

- C# / .NET 10, WPF, решение Visual Studio (`ivan.slnx`, проект `ivan.csproj`).
- СУБД — PostgreSQL, доступ через Entity Framework Core (Npgsql).
- База и таблицы создаются автоматически при первом запуске.
- Параметры подключения (сервер, порт, база, пользователь, пароль) задаются в окне настроек
  приложения и сохраняются в `%LOCALAPPDATA%\TutorSpace\settings.json`.
- Аудиофайлы хранятся на диске в `%LOCALAPPDATA%\TutorSpace\media`, в базе — ссылки на них.
- Запись с микрофона — стандартными средствами Windows, без сторонних библиотек.
- Интерфейс полностью на русском языке.

### 3. Роли и вход

- Две роли: **преподаватель** и **ученик**, вход по логину и паролю (пароли хранятся в виде хеша).
- Преподаватель регистрируется сам; учеников создаёт преподаватель (логин, пароль, имя),
  может прикрепить существующий аккаунт, сбросить пароль, отключить ученика.
- При первом входе ученик заполняет анкету (интересы, уровень языка); без неё интерфейс закрыт.
- На пустой базе — кнопка «Заполнить демо-данными» (готовый преподаватель, ученик и неделя).
- Если подключиться к БД не удалось — показывается окно настроек подключения.

### 4. Функции преподавателя

1. **План недели** (неделя начинается с понедельника):
   - задания по дням: заголовок, описание, ссылка (YouTube распознаётся автоматически),
     длительность в минутах;
   - микро-миссия к заданию (готовые варианты или своя формулировка);
   - публикация недели, дата созвона-разбора, приватные заметки (не видны ученику);
   - чек-лист вопросов к созвону;
   - опция «голосовая самопрезентация» в начале недели (30–60 с, до 3 попыток).
2. **Упражнения внутри задания:**
   - вставить пропущенные слова — синтаксис `{{ответ|вариант::подсказка}}`, проверяется автоматически;
   - ответ на вопрос (минимум слов, пример ответа);
   - тезисы по отрезку видео (таймкоды, ключ преподавателя);
   - повторить за оригиналом (аудио из аудиотеки, до 3 попыток);
   - голосовой монолог.

   Ключ/образец показывается ученику только после его попытки.
3. **Автоматические правила:** «ошибся / справился (порог в %) / закрыл задание →
   повторить задание через N дней или отметить преподавателю», опция «один раз».
   Каждое срабатывание видно преподавателю.
4. **Массовые действия:** сдвиг недели на день, перенос и удаление выбранных заданий,
   копирование недели другому ученику или на другую неделю.
5. **Шаблоны недель:** сохранить неделю как шаблон, применить к любому ученику с любого понедельника.
   Если неделя занята — замена только после подтверждения.
6. **Песочница:** вставить текст недели в простом формате (`#` день, `##` задание, `###` упражнение),
   увидеть разбор с предупреждениями, затем установить ученику или сохранить как шаблон.
7. **Аудиотека:** загрузка файлов или запись с микрофона, название, расшифровка, прослушивание.
8. **Слово дня** для всех своих учеников.
9. **Карточка ученика:**
   - обзор: серия дней, посещения за 4 недели (календарь), задания, ответы, словарь, оценки, анкета;
   - ответы на упражнения и миссии, прослушивание записей, комментарий преподавателя (без оценки);
   - оценки уроков, словарь ученика с состоянием повторений, журнал срабатываний правил.

### 5. Функции ученика

1. **«Сегодня»:** серия дней, число слов к повторению, слово дня, задания на сегодня,
   недоделанные задания прошлых дней.
2. **Постепенное открытие:** задание видно только с наступлением его дня (по дате компьютера)
   и только в опубликованной неделе. Будущие дни показываются закрытыми.
3. **Выполнение задания:** открыть материал, ответить на миссию (обязательно, если нет упражнений),
   выполнить упражнения (история всех попыток сохраняется), комментарий, отметка «выполнено».
4. **Заморозка:** раз в неделю перенести сегодняшний урок на завтра без потери серии
   (кроме воскресенья и уже выполненных уроков).
5. **Оценка урока:** первый урок недели — «хорошо / плохо», остальные — «лучше / так же / хуже
   предыдущего»; при «плохо»/«хуже» обязательно объяснение.
6. **Личный словарь:** добавление, поиск, фильтры, «уже знаю».
7. **Повторение слов** по алгоритму SM-2 с четырьмя ответами («снова / трудно / хорошо / легко»),
   на кнопках показывается следующий интервал.
8. **Профиль:** анкета, смена пароля, список преподавателей.

### 6. Что не переносится из веб-версии

Telegram-бот, JWT-токены, приглашения по ссылке, часовые пояса (используется дата компьютера).

### 7. Требования к качеству

- Бизнес-логика вынесена в отдельный слой сервисов (не в код окон).
- Ошибки пользователя показываются понятным сообщением, приложение не падает.
- Проект открывается и запускается в Visual Studio по F5, пакеты NuGet восстанавливаются автоматически.

### 8. Приёмка

- Проект собирается без ошибок и предупреждений.
- На пустой PostgreSQL база создаётся автоматически, демо-данные заполняются одной кнопкой.
- Сквозные сценарии работают: преподаватель составляет неделю → ученик выполняет задания,
  упражнения, оценивает урок, повторяет слова → преподаватель видит ответы, оценки,
  посещения и срабатывания правил, оставляет комментарии.
- В комплекте README с инструкцией по установке PostgreSQL и запуску.
